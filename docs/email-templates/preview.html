To make these live

  1. Open the Supabase Dashboard for this project → Authentication → Email Templates.
  2. Select each template on the left and replace its body with the matching file below, then save:
  1. Invite user → invite-user.html
  2. Confirm signup → confirm-signup.html
  3. Magic Link → magic-link.html
  4. Change Email Address → change-email.html
  5. Reset Password → reset-password.html
  6. Reauthentication → reauthentication.html

Why here, not in the app's own code

Only invites and password resets are actually triggered by this app's own code today (inviteUserByEmail / resetPasswordForEmail in server/src/users/team.ts) — the other four are Supabase Auth defaults that would otherwise go out unstyled if those flows are ever used. Either way the template HTML lives in Supabase's project settings, not in this repo, so these files are the source of truth to paste in, kept version-controlled here since the dashboard itself doesn't track history.
