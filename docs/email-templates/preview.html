What your account emails will look like

Rendered exactly as they'll reach an inbox — centered card, the SF Cowboy hat mark up top, and one clear button per email. {{ .ConfirmationURL }} below is a stand-in for the real one-click link Supabase fills in when it sends each message.

To make these live

  1. Open the Supabase Dashboard for this project → Authentication → Email Templates.
  2. Select Invite user, replace the body with docs/email-templates/invite-user.html, save.
  3. Select Reset Password, replace the body with docs/email-templates/reset-password.html, save.

Why here, not in the app's own code

Invites and password resets go out through Supabase Auth's own mailer (inviteUserByEmail / resetPasswordForEmail in server/src/users/team.ts), so the template HTML lives in Supabase's project settings rather than in this repo — these files are the source of truth to paste in, kept version-controlled here since the dashboard itself doesn't track history.
